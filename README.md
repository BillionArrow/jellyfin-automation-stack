# Jellyfin Usenet Streaming stack

This is the raw skeleton deployment map for spinning up a totally automated, zero-storage jellyfin media server relying explicitly on Usenet Streaming.

For the full, extensive framework on exactly how to deploy and configure this entire architecture safely, Read the Official Documentation [Here](https://docs.billionarrow.be/media-server-guide.html).

(small warning: automated architectures of this magnitude are unfortunately never a magically simple one-click install. you will actually have to drop into the configurations and manually hook some rules in yourself, but don't panic, every single step is extensively documented in the wiki link above, made by yours truly.)
